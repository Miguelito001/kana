# かな。 — Treino de japonês

Aplicação de estudo de japonês com exercícios de **escrita, vocabulário, gramática, escuta e leitura**, além de modos de desafio.

**[Abrir aplicação](https://kana-treino-rapido.software-rosso.chatgpt.site)**

## Objetivo

Criar uma experiência prática e reutilizável de treino, com diferentes modos de estudo e desafios progressivos.

## Módulos

- **Hiragana e katakana:** reconhecimento dos sistemas de escrita.
- **Kanji e vocabulário:** prática de reconhecimento e associação.
- **Gramática:** exercícios sobre estruturas da língua.
- **Escuta e leitura:** prática de compreensão.
- **Desafios:** modos adicionais para ampliar a prática.

## Executar testes

O repositório documenta testes executados com Node.js:

```bash
node --test tests/*.test.js
```
